# WEBPT

Web pentest tools and scripts built while learning. Authorized targets and lab environments only.

- `arsenal/` - JS/endpoint recon toolkit (secrets, source maps, endpoints, wordlists)
- `log-to-html/` - Logger++ auto-export CSV to an offline HTML dashboard of endpoints and tests
- `burp-extensions/` - which Burp extension to use when, and where to practise

Captured traffic, Burp projects and jars are git-ignored on purpose.
- `engagement/` - scaffold a pentest folder (scope, burp, evidence, notes, report) with screenshot, log and refresh helpers
